# IP 밸류에이션 정량 모델 (V4 실사 보강)

IP 실사 보고서에 숫자를 박기 위한 정량 산식. "추정" 라벨 강제.

## 3대 평가법 산식

### 원가법 (Cost)
- 재생산원가 또는 대체원가 - 감가
- `가치 = Σ(개발 인건비 + R&D + 출원·등록 비용) × 잔존가치율`
- 적용: 초기 자산·시장/수익 데이터 부족 시

### 시장법 (Market)
- 유사 IP 거래·라이선스 비교
- `가치 = 비교거래 단가 × 조정계수(기술성숙도·시장규모·잔존기간)`
- 적용: 비교 거래 존재 시. 한계: 비교 사례 희소

### 수익법 (Income / DCF)
- 미래 초과수익·로열티의 현재가치
- `가치 = Σ [연도별 IP기여수익 / (1+r)^t]`
- r = 할인율(WACC + IP 리스크 프리미엄). 무형자산은 보통 높게

### 로열티 절감법 (Relief-from-Royalty)
- 라이선스를 안 받았을 때 절감되는 로열티의 현가
- `가치 = Σ [매출 × 로열티율 × (1−세율) / (1+r)^t]`

## 업종별 로열티율 벤치마크 (추정·실사 시 검색 갱신)

| 업종 | 로열티율(매출 대비) 추정 |
|------|------------------------|
| 소프트웨어·SaaS | 5~15% |
| 소비재·브랜드(상표) | 3~7% |
| 제약·바이오 | 5~25% (단계별) |
| 전자·하드웨어(특허) | 1~5% |
| 콘텐츠·미디어 | 5~20% |

⚠️ 업종·협상력·독점성에 따라 큰 편차 — 실제 거래 시 비교 사례 검색 필수.

## 라이선스 대가 구조 설계

- 선급금(upfront) + 마일스톤(milestone) + 러닝 로열티(running)
- 미니멈 개런티(minimum royalty) + 상한(cap)
- 분야·지역·기간별 차등
