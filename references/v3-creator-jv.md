# V3 — 크리에이터·합자 IP 귀속·2차적저작물·수익배분

크리에이터 플랫폼·MCN·합자(JV) 구조에서 IP 귀속을 정본화하는 관점. C8·Cre8orClub·KISAS 정본 이슈의 핵심.

## 크리에이터 IP 귀속의 3층 구조

| 층 | 권리 | 귀속 설계 쟁점 |
|----|------|--------------|
| 원저작권 | 크리에이터 창작물 | 원칙 크리에이터 귀속. 플랫폼은 이용허락 |
| 2차 콘텐츠 권리 | 편집·번역·재가공물 | 누가 제작·승인·소유? 사전 합의 |
| 공동저작물 권리 | 협업물 | 공동저작자 전원 합의 필요(저작권법 §48) |

IP 소유권 귀속 계약 체결 이후 발생하는 원저작권·2차 콘텐츠 권리·공동저작물 권리의 귀속 주체를 정하는 조항이 핵심이다(콘텐츠IP 실무). 인플루언서는 이름·이미지가 브랜드가 되는 경제 주체로, 광고표시법·저작권·초상권·세무·계약 리스크가 복합 발생.

## 2차적저작물 설계 (저작권법 §5·§22)

- 2차적저작물 권리 귀속 주체 명확화
- 무단 제작 방지·사전 승인 조건 설정
- 2차 수익배분 기준 명확화 (정률/정액/하이브리드)
- 원저작자 동의 없는 2차사업화 = 침해

## 퍼블리시티·인격표지영리권

2025년 부정경쟁방지법 개정으로 **인격표지영리권**(이름·초상·음성의 영리적 이용 보호)이 명문화됐다. 크리에이터의 이름·얼굴·목소리를 무단 영리 이용하면 부정경쟁행위. 합자·MCN 계약에 인격표지 이용 범위·기간·대가를 명시.

## 합자(JV) IP 귀속 — 한·중 합자 특수 이슈

| 쟁점 | 한국 측 방어 |
|------|------------|
| IP 공동소유 | 공동소유는 처분·라이선스에 전원 동의 필요 → 교착. 단독소유 + 상호 라이선스 권장 |
| 중국 측 출원 | 중국 first-to-file — 한국 측이 핵심 상표·특허를 중국에 선제 출원 |
| 기술수출통제 | 한국 측 핵심기술의 중국 이전이 한국 산업기술보호법·중국 기술수입규제 동시 적용 |
| 합자 종료 시 | IP 회수·라이선스 종료·잔존 사용 처리 사전 약정 |

## KISAS·Cre8orClub 정본 맹점

| 맹점 | 정본 설계 |
|------|----------|
