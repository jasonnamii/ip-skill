# V4 — 라이선싱·기술양수도 딜구조·실사·밸류에이션

IP 라이선스·기술이전·기술양수도(M&A·합작·매각)의 딜 구조와 실사를 다룬다. 투자스킬이 못 다루는 IP 실사의 핵심.

## IP Due Diligence (실사 6축)

매수인·투자자·양수인이 대상 IP의 권리구조를 이해하고 가치·리스크를 산정하는 절차. 6축으로 점검:

| 축 | 점검 내용 |
|----|----------|
| 소유 (Ownership) | 진정한 권리자인가? 직무발명·외주·공동개발 귀속 공백 |
| 범위 (Scope) | 보호 범위·존속기간·territory (국가별 등록 상태) |
| 가치 (Value) | 상업적 관련성·수익 기여·대체 가능성 |
| 분쟁 (Dispute) | 계류·종결된 제3자 분쟁·소송 |
| 제3자 권리 | 라이선스·담보·질권·전용실시권 설정 여부 |
| 침해 (Infringement) | 제3자 권리 침해 가능성·인바운드 특허 주장 |

실사는 M&A·합작투자·라이선스·특허 취득/매각·인바운드 특허 주장 등 IP가 역할하는 모든 거래에서 필요(쿠키딜·김앤장 IP 실무).

## 기술 실사 (Technology Due Diligence)

핵심 제품·기술 아키텍처·코드·특허·R&D 프로세스·기술 인력을 정량·정성 검증해 기술 경쟁력·지속가능성·개발 생산성·기술 리스크를 평가. IP 실사와 병행.

## IP 밸류에이션 (무형자산 평가)

| 방법 | 적용 |
|------|------|
| 원가법 (Cost) | 개발에 든 비용 기준. 초기·대체 자산 |
| 시장법 (Market) | 유사 거래 비교. 비교 사례 있을 때 |
| 수익법 (Income/DCF) | 미래 수익·로열티 현가. 핵심 자산 |
| 로열티 절감법 | 라이선스 안 받았을 때 절감액 |

## 기술이전·라이선스 계약 구조

- 대가: 선급금(upfront) + 마일스톤(milestone) + 로열티(running) 혼합 설계
- 비밀유지(NDA): 퇴직자·협력사 통한 핵심 노하우 유출 방지 강력 조항
- 실시권 범위: 전용/통상, territory, 분야(field of use), 재실시(sublicense)
- 개량발명: 라이선스 기간 중 개량의 귀속·역실시(grant-back)
- 종료: 라이선스 종료 후 재고·잔존 사용·기술 회수

## 표준필수특허(SEP)·FRAND

표준에 필수인 특허(SEP)는 FRAND(공정·합리·비차별) 조건으로 라이선스 의무. 로열티 산정·금지청구 제한 쟁점. 표준화기구 선언·로열티 누적(royalty stacking) 검토.

## 오픈소스 라이선스 컴플라이언스

| 라이선스 | 의무 | SaaS 영향 |
|----------|------|----------|
| MIT | 고지만 | 자유 |
| Apache 2.0 | 고지 + 특허부여 조항 | 특허소송 시 라이선스 종료 |
| GPL 2.0/3.0 | Copyleft — 결합 소스 동일 라이선스 공개 | 배포 시 소스공개. GPL3는 SaaS 특칙 |
| AGPL | 네트워크 제공도 소스공개 의무 | SaaS도 공개 트리거 |

오픈소스 혼입 시 IP 실사에서 **라이선스 양립성·공개 의무 트리거** 점검 — 폐쇄소스 SaaS에 GPL/AGPL 혼입은 소스공개 리스크.
