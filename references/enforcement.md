# IP 침해 대응 (공격·방어 플레이북)

권리화·귀속을 넘어, 침해당했을 때(공격)·경고장 받았을 때(방어)의 실무. M1·M3 보강.

## 공격 (권리자 입장 — 침해 발견)

| 단계 | 수단 | 비고 |
|------|------|------|
| 1 | 침해 증거 확보 | 제품·시점·유사도. 공증·내용증명 |
| 2 | 경고장(내용증명) 발송 | 권리·침해사실·중단 요구. 과도한 위협은 영업방해 역공 리스크 |
| 3 | 침해금지 가처분 | 시간 싸움 — 판매 즉시 중단 효과 |
| 4 | 본안 소송 | 침해금지 + 손해배상(특허 고의 시 3배·영업비밀 5배) |
| 5 | 형사 고소 | 특허·상표·저작권·영업비밀 형사처벌 |
| 6 | 세관 통관보류 | 위조 상품 수입 차단(지재권 세관 신고) |
| 7 | 권리범위확인심판 | 특허심판원 — 침해 여부 공적 확인 |

## 방어 (피경고자 입장 — 경고장 수령)

경고장 무시 = 위험. 무시 시 권리자가 가처분으로 판매 즉시 중단·고의 침해로 3배 배상 인정 리스크.

| 대응 | 내용 |
|------|------|
| 비침해 분석 | 청구항·등록상표와 실제 제품 대비 — 권리범위 밖 입증 |
| 소극적 권리범위확인심판 | 특허심판원 — "내 기술은 청구범위 밖" 확인 |
| 무효심판 | 상대 권리가 무효(진보성·신규성 결여)임을 주장 |
| 회피설계 | 청구항 회피하도록 설계 변경 |
| 라이선스 협상 | 침해 인정 시 로열티 협상으로 전환 |
| 선사용권 항변 | 권리 출원 전부터 사용했음 |

## 분쟁 기관·절차

| 기관 | 역할 |
|------|------|
| 특허심판원 | 무효·권리범위확인 등 특별행정심판 |
| 일반법원(지법·고법) | 침해금지·손해배상 본안 |
| 특허법원 | 심결취소소송 |
| 세관 | 통관보류·지재권 보호 |
| 한국지식재산보호원 | 분쟁 대응 지원사업(IPDS) |

## 손해배상 산정

- 특허·상표·저작권: 침해자 이익·실시료 상당액·법정손해배상
- 고의 침해: 특허 손해액 3배·영업비밀 5배(2024.1.25)
- 입증 곤란 완화: 자료제출명령·구체적 태양 제시 의무

## 무효확률·승소율 (alpha-corpus 연계)

- 경고장 받은 측 무효심판 청구 시 무효 인용률은 특허 유형별 편차 — 통계적 추정
- 가처분 인용은 침해 명백성·긴급성 — 사안별
