# V2 — 플랫폼 자체 IP 권리화·방어

플랫폼이 보유한 자체 IP(특허·상표·코드·DB·브랜드)를 권리화하고 침해로부터 방어하는 관점.

## 자체 IP 자산 인벤토리

| 자산 | 권리화 수단 | 핵심 |
|------|-----------|------|
| 핵심 기술·알고리즘 | 특허 출원 + 영업비밀 병행 | 공개 가능성·역설계 난이도로 선택 |
| 소스코드 | 저작권(자동 발생) + 영업비밀 | 외주개발 시 귀속 계약 필수 |
| 서비스명·로고 | 상표 출원 (선출원주의) | 사업 개시 전 출원, 해외 동시 |
| 데이터베이스 | 저작권법 §93 DB제작자 권리 | 제작완료 시 발생·5년 존속 |
| UI/UX 디자인 | 디자인보호법 등록 | 화면 디자인 등록 가능 |
| 도메인·브랜드 | 상표 + 부정경쟁방지법 | 주지·저명 표지 보호 |

## 외주개발 소스코드 귀속 — 핵심 함정

외주로 개발한 소스코드의 저작권은 **별도 귀속 약정이 없으면 수급인(개발사)에게 귀속**한다. 발주사가 무단 재사용·이전하면 침해. 실무상 외주 소스코드 무단 재사용으로 4천만 원대 손해배상이 인정된 사례가 있다(nepla 실무). 외주개발 계약에는:
- 저작권 양도 조항 명시 (양도 vs 이용허락 구분)
- 2차적저작물작성권 포함 여부 (저작권법 §45②: 별도 약정 없으면 양도에 2차적저작물작성권 불포함)
- 소스코드·산출물 인도 + 원본 폐기 의무

## 업무상저작물 (저작권법 §9)

법인 종업원이 업무상 작성한 저작물은 **법인에게 저작권 귀속**(저작권법 제9조). 단 요건: ① 법인의 기획 ② 종업원이 업무상 작성 ③ 법인 명의 공표 ④ 별도 계약·근무규칙 없을 것. 프리랜서·외주는 업무상저작물 아님 — 별도 양도 필요.

⚠️ 대법원 2025.7.3 선고: 업무상저작물 최초 귀속에 **준거법 적용** 쟁점 — 해외 인력·해외 법인 관여 시 어느 나라 법으로 귀속 판단할지 검토 필요.

## 직무발명 (발명진흥법)

종업원의 직무발명은 **예약승계 규정(근무규칙·계약)이 있으면 사용자가 승계** 가능(발명진흥법 §10·§13). 단 정당보상 의무 발생(§15) — 사용자가 얻을 이익 + 공헌도 고려. 보상규정 미비 시 분쟁·소급 청구 리스크. 직무발명보상 우수기업 인증 시 우선심사·등록료 감면·정부지원 가점.

## 방어 전략

- 특허: 핵심 + 주변 특허로 포트폴리오 울타리(patent fence)
- 상표: 사업 개시 전 + 핵심 시장(한·미·중) 동시 출원
- 영업비밀: 비밀관리성 입증(접근통제·라벨링·서약) — A4 참조
- 모니터링: 경쟁사 출원·침해 정기 감시
